## 🌟 Typographic Specimen

```text
𑄟𑄧𑄚𑄨𑄌𑄴 𑄝𑄬𑄇𑄴𑄇𑄪𑄚𑄴 𑄃𑄌𑄧𑄟𑄚𑄴 𑄦𑄧𑄠𑄬 𑄎𑄧𑄚𑄴𑄟𑄨𑄚𑄴
```

## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Chakma-Changma-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Chakma-Changma-Fonts-Archive/main/install.ps1 | iex
```
